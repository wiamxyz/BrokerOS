# Iconly icons

Official Iconly Pro Light artwork, obtained through the account’s authorized MCP connection. Lottie artwork is bundled locally and loaded only when hovered. No runtime connection to Iconly or account key is required. Adapted from HandyOS for BrokerOS at the user’s explicit request. These assets are application UI resources, not a standalone icon pack.

Plus icons, chevrons, and directional controls (including sidebar open/close) stay static. Other icons play once on each pointer entry. Leaving resets to the still frame; keeping the pointer over a control never repeats playback. Reduced motion and touch-only devices remain still. Other utility symbols without a matching animated asset use a single short stroke reveal.
